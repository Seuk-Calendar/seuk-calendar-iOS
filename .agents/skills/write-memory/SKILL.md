# Write Memory

실패/거부/교정 내역을 누적해 다음 작업 전에 재사용 가능한 `memory`로 남깁니다.

## 트리거 조건(When to Use)
- 같은 유형 실수가 반복될 가능성이 있을 때
- 사용자가 명확히 수정/거부 방향을 제시했을 때
- 작업 범위 이탈, 컨벤션 누락, 브랜치 혼선 등 재발 비용이 클 때

## 노이즈 방지 규칙(Noise Filter)
다음 조건을 만족할 때만 기록합니다.
- 재발 가능성이 있다.
- 한 번의 누락으로 비용이 커질 수 있다.
- 재사용 가능한 예방 규칙으로 일반화 가능하다.

## 작성 단계(Authoring Steps)
1. `templates/memory-template.md`를 복사합니다.
2. 파일명을 `YYYY-MM-DD-short-slug.md`로 저장합니다.
3. `키워드/사전 점검/예방 규칙`을 반드시 작성합니다.
4. `index/MEMORY_INDEX.md`에 한 줄 추가합니다.
5. 사용자에게 기록 완료를 출력으로 알립니다.

## 사용자 알림(User Notification)
메모리 저장 후 아래와 같이 알립니다.
```markdown
📝 memory 기록 완료: <파일명>
- 핵심 예방 규칙: ...
- 다음 작업 적용 체크: ...
```

## 금지 사항(Do Not Do)
- 단순 로그/감상 수준 내용은 기록하지 않습니다.
- 키워드 없이 서술형 텍스트만 남기지 않습니다.
