# GitHub Issue Creation Examples

## 예시 1: 사용자가 명시적으로 이슈 생성 요청

### 대화

```
사용자: 새로운 기능 추가 작업을 이슈로 만들어줘

AI: 먼저 관련된 기존 이슈가 있는지 확인하겠습니다.

[gh issue list 실행]

검색 결과: 관련 이슈 없음

이 작업을 GitHub 이슈로 생성할까요?

작업 내용: 새로운 기능 추가

사용자: 응

AI: [이슈 생성 중...]

✅ 이슈가 생성되었습니다!

📋 이슈 정보:
- 번호: #123
- 제목: 새로운 기능 추가
- URL: https://github.com/owner/repo/issues/123
```

## 예시 3: 기존 이슈가 있는 경우

### 대화

```
사용자: 로그인 버그 수정 이슈 만들어줘

AI: 관련된 기존 이슈가 있는지 확인하겠습니다.

[gh issue list --search "로그인 버그" 실행]

검색 결과:
- #98: 로그인 버그 수정 필요 (open)
- #87: 로그인 화면 오류 (closed)

이미 관련 이슈가 존재합니다:
- #98: 로그인 버그 수정 필요 (open)

새로운 이슈를 생성하시겠습니까, 아니면 기존 이슈를 사용하시겠습니까?

사용자: 기존 이슈 사용할게

AI: 알겠습니다. 기존 이슈 #98을 사용합니다.
```

작업 내용: 버그 리포트

📋 이슈 정보:
- 번호: #125

## 예시 5: 라벨 지정

### 대화

```
사용자: UI 개선 작업 이슈 만들어줘. enhancement 라벨 붙여줘

AI: 관련된 기존 이슈가 있는지 확인하겠습니다.

[gh issue list --search "UI 개선" 실행]

검색 결과: 관련 이슈 없음

이 작업을 GitHub 이슈로 생성할까요?

작업 내용: UI 개선 작업
라벨: enhancement

사용자: 응

AI: [이슈 생성 중...]

gh issue create \
  --title "UI 개선 작업" \
  --body "..." \
  --label "enhancement" \
  --assignee "@me"

✅ 이슈가 생성되었습니다!

📋 이슈 정보:
- 번호: #126
- 제목: UI 개선 작업
- 라벨: enhancement
- 담당자: @me (자동 할당)
- URL: https://github.com/owner/repo/issues/126
```

> **참고**: 담당자는 기본적으로 이슈 작성자(@me)로 자동 할당됩니다.

## 예시 6: 복잡한 작업 계획과 함께

### 대화

```
사용자: 사용자 프로필 기능을 전체적으로 리팩토링하려고 해.
       - API 레이어 분리
       - 상태 관리 개선
       - UI 컴포넌트 재구성
       이렇게 3가지를 해야 해

AI: 사용자 프로필 기능 리팩토링 작업이네요.
총 3가지 하위 작업이 있습니다.

관련된 기존 이슈가 있는지 확인하겠습니다.

[gh issue list --search "프로필 리팩토링" 실행]

검색 결과: 관련 이슈 없음

이 작업을 GitHub 이슈로 생성할까요?

작업 내용: 사용자 프로필 기능 리팩토링
- API 레이어 분리
- 상태 관리 개선
- UI 컴포넌트 재구성

사용자: 네

AI: [이슈 생성 중...]

본문 구성:
## 작업 내용

사용자 프로필 기능을 전체적으로 리팩토링합니다.

## 상세 설명

프로필 기능의 구조를 개선하여 유지보수성과 확장성을 높입니다.

## 체크리스트

- [ ] API 레이어 분리
- [ ] 상태 관리 개선
- [ ] UI 컴포넌트 재구성

✅ 이슈가 생성되었습니다!

📋 이슈 정보:
- 번호: #127
- 제목: 사용자 프로필 기능 리팩토링
- URL: https://github.com/owner/repo/issues/127
```

## 주의사항

1. **중복 확인 필수**: 항상 `gh issue list --search`로 기존 이슈 확인
2. **사용자 확인 필수**: 자동으로 이슈를 생성하지 않고 반드시 확인 받기
3. **템플릿 우선**: 템플릿이 있으면 반드시 사용
4. **명확한 제목**: 50자 이내로 작업 내용이 명확히 드러나도록
5. **체크리스트 활용**: 하위 작업이 여러 개면 체크리스트로 구조화
6. **자동 담당자 지정**: 모든 이슈는 기본적으로 작성자(@me)가 담당자로 할당됨
