# Design Guide

이 문서는 디자인을 수정할 때 지켜야 할 규칙입니다.

## 기본 원칙

- 컴포넌트를 만들 때는 반드시 디자인 시스템을 사용합니다.
- 폰트, 사이즈, 스페이싱은 임의 값 대신 디자인 시스템 토큰을 사용합니다.

## 컴포넌트 티어 분류

컴포넌트는 복잡성에 따라 `Tier1`, `Tier2`, `Tier3`로 구분합니다.

### Tier1

- 가장 기초가 되는 단일 컴포넌트입니다.
- 예: `Button`, `TextField`, `Icon`

### Tier2

- 복수 개의 `Tier1` 컴포넌트로 이루어진 조합 컴포넌트입니다.
- 예: `검색 바`(아이콘 + 입력창 + 버튼), `라벨 포함 입력 필드`

### Tier3

- 복수 개의 `Tier2` 컴포넌트로 구성된 상위 컴포넌트입니다.
- 예: `로그인 폼 섹션`, `카드 리스트 섹션`
