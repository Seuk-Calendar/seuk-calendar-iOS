# PR Convention

## 제목 형식

```
(#<이슈번호>) <제목>
```

## 제목 규칙

- "~합니다." 와 같이 구어체를 사용한다.
- 해당 PR의 작업 내용을 명확하게 전달한다.

## 제목 예시

```
(#312) AI 에이전트 환경을 구축합니다.
(#999) 홈 화면 피드 목록을 구현합니다.
(#100) 로그인 시 크래시가 발생하는 문제를 수정합니다.
```

## 본문 규칙

- `.github/PULL_REQUEST_TEMPLATE.md` 템플릿의 섹션 구조를 그대로 따른다.
- 임의로 섹션을 추가하거나 제거하지 않는다.
- 사람이 충분히 이해하기 쉽도록 작성한다.
- 각 섹션의 주석 안내에 맞게 내용을 채운다.

## 본문 섹션

| 섹션 | 설명 |
|------|------|
| 주요 작업 내용 | 해당 PR에서 작업한 내용을 한 눈에 파악하기 좋게 작성 |
| 참고사항 | 리뷰어에게 참고하면 좋을 내용 작성 |
| 스크린샷 | UI 변경이 있는 경우 스크린샷 첨부 |
